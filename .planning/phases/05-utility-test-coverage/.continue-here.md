# BLOCKING CONSTRAINTS — Read Before Anything Else

- [ ] CONSTRAINT: **Timezone-unsafe date fixtures** — writing a test date as a midnight-UTC ISO string (e.g. `new Date("2026-01-07")`) renders as the *previous* calendar day when `Intl.DateTimeFormat` (no `timeZone` option) formats in a negative-offset local timezone. Confirmed: this Mac is `America/Denver` (UTC-7); GitHub Actions runners default to UTC. A test written and verified locally against a midnight-UTC date can pass locally and fail in CI (or the reverse). **Mitigation: always use a noon-UTC timestamp** (e.g. `"2026-01-07T12:00:00Z"`) for any fixed test date — safe across any realistic timezone.
