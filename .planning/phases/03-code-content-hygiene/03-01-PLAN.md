<threat_model>
Security enforcement is on for this project at OWASP ASVS level 1, blocking on `high`. This plan
deletes dead content and edits build configuration in a static site with no server runtime, no
authentication, and no user input handling, so its genuine security surface is small. The register
below is deliberately short rather than padded.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository -> published `dist/` | Anything left in `src/content/` can become publicly served HTML if a locale or draft flag is flipped; deleting dead content shrinks what can be published by accident |
| developer shell -> filesystem | `npm run remove-multilingual` performs unattended recursive `fs.rm` on directories matched by name, from a working directory the operator chooses |
