# Milestone v1.0: Launch-Quality Punch List

**Status:** ✅ SHIPPED 2026-09-16
**Phases:** 1-3
**Total Plans:** 3 (Phases 1 and 2 required no plans — verified/completed directly)

## Overview

This milestone closed out the remaining pre-launch/launch-quality punch list on Ryc's already-live consulting site (onemoregreatidea.com), which remains its own dedicated Astro site permanently — the askryc.com/.net/.mt domains were split out to a separate WordPress project and were out of scope here. The work was three independent buckets of maintenance: stop two empty placeholder pages from being publicly reachable, add a proper social-sharing image, and retire two known pieces of tech debt (legacy `.mdx` content and an untyped form utility) that had been working "by accident."

## Phases

### Phase 1: Draft Placeholder Cleanup

**Goal**: The two empty, unfinished case-study placeholder pages cannot be reached by a visitor who guesses or is given their URL
**Depends on**: Nothing (first phase)
**Requirements**: TECHDEBT-04
**Plans**: None needed — verified already satisfied by existing code

**Details:**
`getCollectionCTM()` in `themes/lumio/src/lib/contentParser.astro` already filters out `draft: true` entries in production builds, so `case-study-5`/`case-study-6` never get a static route generated at all. Confirmed empirically: `dist/case-studies/` contains only `vongo`, `ccrms`, `horizongo`, `inktix` after a production build. No code changes were needed. This corrected an earlier, inaccurate concern in `.planning/codebase/CONCERNS.md` that was based on reading `remove-draft-from-sitemap.mjs` in isolation. Re-verified live in production during the v1.0 milestone audit (2026-09-16): both URLs return 404.

### Phase 2: Social Sharing

**Goal**: Sharing a link to the site on social platforms produces a correct, on-brand preview instead of a missing or default image
**Depends on**: Nothing (independent of Phase 1)
**Requirements**: CONTENT-04
**Plans**: None needed — the `og:image`/`twitter:image` meta-tag plumbing already existed; the only gap was the missing image file

**Details:**
Generated a 1200×630 branded OG image (headshot + name + tagline on the brand blue background, matching the homepage hero copy) via a `sharp`-based composite script, reviewed and approved by Ryc, placed at `themes/lumio/public/images/og-image.jpg`. Verified in a production build and re-verified live in production during the v1.0 milestone audit.

### Phase 3: Code & Content Hygiene

**Goal**: The codebase's content-format and type-safety debt is eliminated, and dead locale content is removed
**Depends on**: Nothing (independent cleanup work)
**Requirements**: CONTENT-05, TECHDEBT-01, TECHDEBT-02, TECHDEBT-03
**Plans**: 3/3 plans executed

Plans:

- [x] 03-01: Removed disabled French locale content, i18n/menu data, and locale-only tooling scripts (CONTENT-05) — 86 tracked files removed, 45-route byte-parity proven before/after
- [x] 03-02: Migrated 9 blog posts and 6 case studies from `.mdx` to `.md` with byte-identical rendered output (TECHDEBT-01, TECHDEBT-02) — 4/45 pages had a documented zero-impact serializer-escaping exception
- [x] 03-03: Typed `window.HSSelect` via an ambient declaration and removed `@ts-nocheck` from FormHandle.ts (TECHDEBT-03)

**Details:**
Human verification of the contact form after execution found and fixed a real pre-existing production bug: `window.HSSelect` was never assigned anywhere in the codebase, so every successful contact-form submission threw inside `formReset()`, silently caught and displayed as a false "Oops!" error while the email actually sent fine. Fixed by assigning `window.HSSelect = HSSelect` in both `ContactForm.astro` and `GlobalScripts.astro` (commit `441ecab`). Live-confirmed the success message displays correctly and the dropdown visually resets.

## Milestone Summary

**Key Decisions:**

- onemoregreatidea.com stays permanently separate from askryc.com/.net/.mt — the latter three became a separate WordPress project (`/Users/ryc/projects/askryc`)

- Pre-existing v2 backlog carried forward unchanged: TECHDEBT-05 (CI pipeline), TECHDEBT-06 (broader test coverage), TECHDEBT-07 (remove unused netlify.toml/wrangler.toml/deploy:cf)
